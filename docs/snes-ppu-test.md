# Authorized PPU measurement test

Ben requested “Arm I” after the general PPU fixes. This authorizes a separate
experimental one-shot measurement run; it does not promote the core to
production. New A7 prices and predicted audio deficit are explicitly unknown.
The existing installation pricing gate is deferred only for this authorized
measurement experiment so those prices can be obtained.

56 epochs retain every frame and PCM sample: the final v5 combination runs
18 archived contexts twice, with frozen demand-v3 Meteor/Quasar controls in
opposite orders. Another16 epochs compare ordinary OBJ, shapes (opaque,
clipped, sparse plain/math), and bulk-depth families against demand-v3 on
Meteor/Quasar in forward/reverse blocks. No row-cache experiment, nested PPU
clocks, frequency pinning or CPU/APU changes. State payloads remain identical;
only the wrapper's core identity header migrates for each binary.

The actual ARM controller must pass56 epochs/67200 calls, expected effect
properties and lossless accounting before installation. The consuming native
client, fault/retry/state/direct output, one-shot wrapper and device ABI are
checked. The reporter rejects mock telemetry as physical evidence. Offline
core exactness is reused by the published ordinary core hashes, not inferred
from controller property checks. Raw/private progress, ROM and vendor binaries
remain private; Git receives source and qualification metadata only.

The guarded installer requires a fresh strict card archive, clean FAT/known
serial, unchanged protected stock/adapter/boot/ROM/progress, a clean pushed
source commit and all prepared payload/proof hashes. It writes only the new
retro/snes-ppu-test1 directory, existing launch dispatcher and one-shot marker.
Readback and FAT checks run after payload and after arm, with guarded rollback
on failure. Previous test outputs remain intact. Readiness is not installation;
an installation receipt records the actual armed state separately.

Safely eject I:, insert it with the handheld off, and cold-boot. Allow about
25–30 minutes for the56 epochs and log flushing. Wait for the stock launcher,
power down and return I:. Select+Start aborts; the next reboot uses stock.

On return, archive before writes. Compare valid matched heavy intervals and
recovery, complete cumulative reserve, pointer integrity, full drawings/PCM
and independent failure fields. A1200-call completion with pointer drift fails.

reserve/pointers for the full effect/recovery. Negative family prices or renewed
collapse reject the corresponding optimization.20 percent production headroom
